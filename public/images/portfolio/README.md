# Portfolio Images Folder

Place your portfolio images here.

## Required Images:

### Featured Film:
- `carnitapu-featured.jpg` - Featured film hero image (wide format, 21:9 aspect ratio recommended)

### Portfolio Projects:
- `listening-to-films.jpg` - Documentary project image
- `static-bloom.jpg` - Music Video project image
- `false-memory.jpg` - Short Film project image
- `the-signal.jpg` - Commercial project image
- `artifact.jpg` - Experimental project image
- `light-leaks.jpg` - Brand Film project image

## Image Guidelines:

- **Format:** JPG, PNG, or WebP
- **Featured film:** 1920x823px or similar 21:9 aspect ratio
- **Portfolio grid:** 1280x720px or similar 16:9 aspect ratio
- **File size:** Aim for under 500KB per image (optimize for web)
- **Quality:** High quality, but compressed for web performance

## Adding Images:

1. Export your images from your editing software
2. Optimize them using tools like TinyPNG or ImageOptim
3. Name them exactly as listed above
4. Place them in this folder

The website will automatically display them!
